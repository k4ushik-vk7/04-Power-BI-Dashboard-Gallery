## 📌 About This Repository

Welcome to my **Power BI Dashboard Gallery** — a collection of independent dashboard projects developed using Microsoft Power BI.

This repository showcases my practical experience in data visualisation, dashboard design, business reporting and analytical storytelling across different business domains.

Each dashboard focuses on presenting data through meaningful visualisations, key performance indicators and interactive reporting elements to make business information easier to understand.

## 🎯 Objectives

- Develop interactive and user-friendly Power BI dashboards.
- Practise data visualisation and analytical storytelling.
- Present business information through meaningful KPIs.
- Explore different business domains and analytical scenarios.
- Improve dashboard layout, design and reporting techniques.
- Convert raw data into clear and actionable visual insights.
